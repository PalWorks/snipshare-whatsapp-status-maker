  1. Open developers.giphy.com and sign in.
  2. Create an app and choose API, not SDK.
  3. Copy its API key and paste it below.

Remove your GIPHY key? GIF search stops using it.

  1. Open partner.klipy.com and sign in or sign up.
  2. On its API keys page, create a key.
  3. Copy the key and paste it below.
